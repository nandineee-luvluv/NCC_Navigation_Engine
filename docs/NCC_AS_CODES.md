## NCC Part A - General Provisions

### A1 - Scope and General Provisions

| Code | Title | Description |
|------|-------|-------------|
| **NCC A1G1** | General Requirement | Establishes the general requirement that buildings must be designed and constructed in accordance with the NCC |
| **NCC A1G2** | Application | Defines the scope of application for different building types |
| **NCC A1G3** | Deemed-to-Satisfy Provisions | Outlines the deemed-to-satisfy solutions for compliance |

### A3 - Performance Requirements

| Code | Title | Description |
|------|-------|-------------|
| **NCC A3G1** | Performance Requirements | Establishes the performance requirements that buildings must meet |
| **NCC A3G2** | Verification Methods | Describes methods to verify compliance with performance requirements |
| **NCC A3G3** | Deemed-to-Satisfy Provisions | Provides deemed-to-satisfy solutions for performance requirements |

### A6 - Classification of Buildings

| Code | Title | Description |
|------|-------|-------------|
| **NCC A6G1** | Building Classification | Defines the 10 building classifications (Classes 1-10) |
| **NCC Table A6G1** | Classification Table | Provides detailed criteria for determining building class |
| **NCC A6G2** | Mixed-Use Buildings | Guidance on classifying buildings with multiple uses |

## NCC Part B - Fire Resistance & Structural

### B1 - Fire Resistance

| Code | Title | Description |
|------|-------|-------------|
| **NCC B1G1** | Fire Resistance Levels | Defines FRL (Fire Resistance Level) requirements |
| **NCC B1G2** | Fire Resistance Standards | References AS 1530 series for fire testing |
| **NCC B1G3** | Construction Types | Specifies acceptable construction types for different FRLs |
| **NCC B1G4** | Sprinkler Systems | Requirements for automatic sprinkler systems |

### B2 - Structural

| Code | Title | Description |
|------|-------|-------------|
| **NCC B2G1** | Structural Performance | Establishes structural performance requirements |
| **NCC B2G2** | Design Actions | Defines design actions (loads) to be considered |
| **NCC B2G3** | Structural Design Standards | References AS 1170 series for structural design |
| **NCC B2G4** | Geotechnical Investigation** | Requirements for site investigation and foundation design |

### B3 - Safety (Fire Escape)

| Code | Title | Description |
|------|-------|-------------|
| **NCC B3G1** | Emergency Evacuation | Requirements for emergency evacuation routes |
| **NCC B3G2** | Exit Requirements | Specifies exit widths, heights, and travel distances |
| **NCC B3G3** | Stairways** | Design requirements for stairways and ramps |

## Australian Standards

### AS 1170 - Structural Design Actions

| Standard | Title | Application |
|----------|-------|-------------|
| **AS 1170.0** | General Principles | Fundamental principles for structural design |
| **AS 1170.1** | Permanent, Imposed & Other Actions | Dead loads, live loads, and other actions |
| **AS 1170.2** | Wind Actions | Wind load calculations and design |
| **AS 1170.3** | Earthquake Actions | Seismic design requirements |
| **AS 1170.4** | Earthquake Actions - Commentary | Guidance on earthquake design |

### AS 1530 - Fire Testing

| Standard | Title | Application |
|----------|-------|-------------|
| **AS 1530.1** | Non-Combustibility Test | Testing for non-combustible materials |
| **AS 1530.2** | Ignitability Index & Smoke Production | Flammability testing |
| **AS 1530.3** | Smoke & Toxic Gas Release | Fire performance testing |
| **AS 1530.4** | Fire Resistance Testing | FRL determination testing |

### AS 3600 - Concrete Structures

| **AS 3600 Section 2** | Materials | Concrete and reinforcement specifications |
| **AS 3600 Section 3** | Design | Structural design principles and calculations |
| **AS 3600 Section 4** | Detailing** | Reinforcement detailing requirements |

| **AS 4100 Section 3** | Design | Limit states design approach |

### AS 1684 - Timber Structures

### AS 1012 - Testing of Concrete

## Phase-by-Phase References

### Phase 1: Project Setup

**NCC References:**
- NCC Part A1 - Scope and General Provisions
- NCC Part A3 - Performance Requirements

**AS References:**
- AS 1170.0 - General Principles

**Key Documents:**
- Client brief and site address
- Building purpose and occupancy type
- Number of storeys and gross floor area
- Preliminary structural concept

---

### Phase 2: Building Classification

**NCC References:**
- NCC A6G1 - Building Classification
- NCC Table A6G1 - Classification Table

**Key Considerations:**
- Primary use determination
- Secondary uses and mixed-use buildings
- Special use buildings
- Exemptions and modifications

---

### Phase 3: Compliance Pathway

**NCC References:**
- NCC C2D4(1) - Compliance Pathway Selection
- NCC C2D4(2) - Deemed-to-Satisfy Solutions
- NCC A3G2 - Verification Methods

**Pathways:**
- **DTS (Deemed-to-Satisfy):** Prescriptive compliance with NCC provisions
- **Performance:** Demonstration of performance requirements through analysis
- **Hybrid:** Combination of DTS and Performance approaches

---

### Phase 4: Importance Level

**NCC References:**
- NCC A3G1 - Performance Requirements

**Importance Levels (IL):**
- **IL 1:** Low importance (minimal consequences of failure)
- **IL 2:** Moderate importance (moderate consequences)
- **IL 3:** High importance (high consequences)
- **IL 4:** Critical importance (critical consequences)

---

### Phase 5: Structural Actions

**NCC References:**
- NCC B2G2 - Design Actions
- NCC B2G3 - Structural Design Standards

**AS References:**
- AS 1170.1 - Permanent & Imposed Actions (G, Q)
- AS 1170.2 - Wind Actions (W)
- AS 1170.3 - Earthquake Actions (E)
- AS 1170.4 - Earthquake Actions Commentary

**Design Actions:**
- **G:** Permanent (Dead) Loads
- **Q:** Imposed (Live) Loads
- **W:** Wind Actions
- **E:** Earthquake Actions
- **S:** Snow Loads
- **Flood:** Flood Actions

---

### Phase 6: Material Standards

**NCC References:**
- NCC B2G3 - Structural Design Standards

**AS References:**
- **Concrete:** AS 3600, AS 1012
- **Steel:** AS 4100, AS 3679
- **Timber:** AS 1684, AS 1720
- **Masonry:** AS 3700
- **Geotechnical:** AS 2870, AS 4678

---

### Phase 7: Structural Analysis

**NCC References:**
- NCC B2G1 - Structural Performance
- NCC B2G3 - Structural Design Standards

**Analysis Types:**
- **ULS (Ultimate Limit State):** Strength and stability
- **SLS (Serviceability Limit State):** Deflection and cracking
- **Fatigue:** For cyclic loading
- **Dynamic:** For earthquake and wind

---

### Phase 8: Fire Resistance

**NCC References:**

- AS 1530.4 - Fire Resistance Testing
